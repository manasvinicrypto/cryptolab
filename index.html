CryptoLab

Four ciphers, five hash algorithms, zero servers.

An in-browser toolkit demonstrating classical, symmetric, and asymmetric encryption alongside cryptographic hashing. Every operation below runs entirely client-side in JavaScript — nothing is sent anywhere.

Caesar Cipher

substitution · symmetric

Shifts every letter forward by a fixed number of places in the alphabet. Case is preserved and non-letter characters pass through unchanged.

Vigenère Cipher

polyalphabetic · symmetric

Uses a repeating keyword to apply a different shift to each letter, making frequency analysis far harder than a Caesar cipher.

AES-256 (GCM)

Web Crypto API · symmetric

Industry-standard authenticated encryption. Your passphrase is stretched into a 256-bit key with PBKDF2, and a random salt + IV are generated per encryption so the same input never produces the same ciphertext twice.

ⓘ How it works: PBKDF2 (100,000 iterations, SHA-256) derives the key from your passphrase and a random salt. AES-GCM then encrypts with a random 12-byte IV. Salt + IV + ciphertext are packed together and Base64-encoded, so decryption only needs the same passphrase.

RSA-OAEP

Web Crypto API · asymmetric

Uses a mathematically linked key pair instead of one shared secret: anyone can encrypt with your public key, but only your private key can decrypt it. This is what makes secure communication possible between people who've never met — the basis of HTTPS, PGP, and SSH.

ⓘ How it works: RSA-OAEP pads the message with randomness before the RSA transform, which prevents the classic attacks plain textbook RSA is vulnerable to. Because RSA is slow and can only encrypt small messages, real systems (like TLS) actually use RSA only to exchange a short AES key, then switch to AES for the bulk data — the best of both algorithms.

Hashing

Web Crypto API + MD5 · one-way

Produces a fixed-length fingerprint of any input. Unlike encryption, hashing is one-way — there is no "decrypt". This is one way hashing supports the integrity part of the CIA triad: if a file changes even slightly, its hash changes completely, so comparing hashes reveals tampering. One input, five algorithms, computed side by side.
